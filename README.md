<div align=center>
  
Este projeto consiste na criação de um sistema de **Cadastro de Produtos**, desenvolvido com **PHP, HTML e MySQL**.

A atividade tem como objetivo criar um formulário para cadastrar produtos, realizar a validação dos dados informados e inserir as informações válidas em uma tabela do banco de dados.

</div>

---

<div align="center">

[![Typing SVG](https://readme-typing-svg.herokuapp.com?font=Fira+Code&size=24&duration=8000&pause=1500&startDelay=0&color=777BB4&center=true&vCenter=true&width=750&lines=🎯+Objetivo+da+Atividade)](https://git.io/typing-svg)

</div>

<div align=center>

Criar um sistema de cadastro **simples, funcional e validado**, utilizando PHP para processar os dados do formulário e MySQL para armazenar os produtos cadastrados.

</div>

---

<div align="center">

[![Typing SVG](https://readme-typing-svg.herokuapp.com?font=Fira+Code&size=24&duration=8000&pause=1500&startDelay=0&color=777BB4&center=true&vCenter=true&width=750&lines=📝+Funcionalidades+Implementadas)](https://git.io/typing-svg)

</div>

<div align=center>

🛒 **Cadastro de Produtos:** formulário para informar o nome e o preço do produto.<br>
✅ **Validação do Nome:** verifica se o nome do produto foi preenchido.<br>
💰 **Validação do Preço:** verifica se o preço é um número maior que zero.<br>
💾 **Inserção no Banco:** os produtos válidos são armazenados na tabela `produtos`.<br>
📢 **Mensagens de Retorno:** exibe mensagens de sucesso ou erro abaixo do botão de cadastro.<br>
🗄️ **Banco de Dados:** utilização do banco `exercicio` para armazenar os produtos.

</div>

|---|---|
